## C. Bugs fixed and evidence

1. Direct exporter file execution could not import src, so it exited before bind.
   Resolve the repository root from __file__. Regression starts --help from /tmp;
   owned 9200 verification started the actual standalone entry point from another
   directory, returned HTTP 200 and valid exposition, and existing Prometheus UP=1.
2. Standalone report reload swallowed exceptions and retained previous healthy
   observations. Explicit diagnostics now clear the snapshot and increment errors.
   Corrupt-file regression verified both behavior and JSONDecodeError diagnostic.
3. Prometheus reuse trusted buildinfo without checking scrape configuration.
   Verify its active exporter target/job. Mocked mismatch regression verifies
   nonzero session status and no network startup.
4. Fault parameters could carry invalid values; partial application was untracked
   until both interfaces changed, and tc failures were often only printed by
   Mininet. Validate parameters, inspect TCIntf tcoutputs and both qdiscs, track
   before first change, roll back failures, attempt both restores, retain ownership
   on restore errors. Verified with fault logic and injected-failure mocks only.
5. HTTP errors could contaminate network inference; absent observations were
   classified healthy. Restrict detector hints to ICMP latency/loss, report
   missing coverage inconclusive, and expose the actual inference state. Unit
   regressions plus five-stage simulation passed; confidence remains heuristic.
6. Invalid detector configuration could divide by zero or prevent warm-up forever.
   Validate positive finite deltas/thresholds and sample/window limits. Focused
   invalid-input and existing detector-calculation tests passed.
7. Phase 6 simulation required one private, ignored historical directory. Use a
   checked-in synthetic fixture or explicit baseline. Portable five-stage simulation
   passed; synthetic throughput changes are not physical TCP measurements.
8. Failed live probes could cause arithmetic on null in acceptance checks. Assert
   omitted exposition values instead. Existing missing-value tests and recorded
   ingestion passed; kernel fault acceptance remains unexecuted.
9. Three-packet random 25% live loss cannot reliably establish an outage. Current
   live acceptance uses deterministic 100% app-DB loss; simulation retains 25%.
   This live scenario change is documented and still requires root validation.
10. Setup hardcoded python3.14-venv, hid OVS startup errors, and isolated apt Mininet
    from its venv. Use python3-venv/system-site-packages and fail clearly. Shell
    syntax passed; full installation was not executed on a fresh host.
11. Invalid ping statistics/negative iperf fields could enter successful reports.
    Reject them at parsing. Focused regressions and existing parsing tests passed.
12. Interactive topology lacked guaranteed lifecycle cleanup on exceptions.
    Route it through experiment_network; existing lifecycle mocks and topology
    structural tests passed. Interactive/live invocation requires root acceptance.
13. Fullerenes repeated generation could erase handwritten instructions, including
    through nested marker text in generated comments. Wrapper snapshots/restores
    existing agent files and refuses watch. Two full init regenerations and two
    incremental refreshes preserved all three agent files byte-for-byte. Actual
    MCP handshake/query still passed afterward.
